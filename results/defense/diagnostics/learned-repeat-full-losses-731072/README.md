# Learned-duration failure comparison

The [shared 10,480-point best](policy-1-losses.png) and
[run 54's 9,980-point replay](policy-2-losses.png) show the same broad
right-opening barrier sequence. In approach frames the ship remains left of
the opening. The variable-duration policy has not demonstrated passage.

The best earns 2,620 on every life; run 54 earns 2,500 / 2,450 / 2,600 / 2,430.
Those score differences do not measure exact course position. Panels are
aligned to a visible white-flash heuristic, or the visible life loss when no
flash was sampled—not to a known physical collision. Some frames contain
failure animation. These images do not distinguish wall and projectile deaths.

[Provenance and window metadata](report.json) include checked source hashes
and the original independent native replay verification. This read-only
comparison uses selected replays, not a representative matched evaluation.
No hidden RAM, policy changes, route instructions, rewards or training
examples were generated. The stronger shared replay remains preserved.
