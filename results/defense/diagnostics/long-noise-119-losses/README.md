# The new score parent still meets the same visible barrier

The longer noise-trained PPO checkpoint is a confirmed **score** improvement,
not a stage-clear result. This read-only comparison checks native-verified
best-effort traces from its second fresh seed set and from the independently
confirmed ordinary-action parent. `rl.defense_loss_probe` checks the source
manifest hashes, original neural-action verification, displayed score sum and
all four visible loss events, then re-renders only recorded screen bytes.
It neither plays new games nor changes weights, actions, rewards or training.

- [New score parent's panels](policy-1-losses.png): each of four lives gained
  **2,620** points before the visible ship-loss marker.
- [Older confirmed parent's panels](policy-2-losses.png): the same four
  **2,620**-point life totals in a separate selected replay.

Both sheets again show the broad barrier sequence and a ship near the
centre/left while a right-side opening approaches. Thus the independently
measured score gain largely reflects fewer *early* collapses, not observed
passage of this recurring obstacle. The selected seeds differ and best-score
replays are not representative of all 128 games. Equal displayed life scores
do not prove identical course coordinates or physical collisions; the white
flash is only a visible alignment marker and may lag the decisive mistake.
Pure movement commands occupy 51.6–60.9% of the new policy's and
59.4–60.9% of the old parent's 64-action pre-marker windows, so neither
trace simply lacks movement choices. Movement-command counts are not ship
displacement. In stage one, Space suppresses arrow movement, but these
panels do not identify a causal action or prescribe a route.

[Machine-readable provenance and windows](report.json) retain the source
hashes and limitations. Neither diagnostic replay completed the mission;
the globally ranked verified best remains unchanged.
